# クリニック向け セミセルフレジ（自作）

添付の「OWEN」のようなクリニック用セミセルフレジを、**中古の汎用機＋自作ソフト**で構築するプロジェクトです。
高額な月額保守（15,000〜21,000円/月・5年縛り）と高額スポット部品を避け、
**釣銭機は「替えがきく定番中古機」、ソフトは自作（無償保守）** で組みます。

## 構成

```
自動釣銭機(Glory RT-300系/中古)  ─RS-232C─┐
バーコードリーダー(USB-HID)      ─USB────┤
レシートプリンタ(EPSON TM系)     ─LAN/USB─┤   ミニPC 1台
タッチモニタ ×2 (患者/スタッフ)  ─HDMI+USB┘   └ Node.js バックエンド
UA-P10NA(導入済/半連動) ・ PayPay静的QR(札立て)     └ 両画面ミラー(WebSocket)
```

- **両面ミラー**：1つのバックエンドが患者側/スタッフ側の2画面へ同じ状態を配信。どちらからでも操作可能。
- **レセコン連携**：領収書バーコードの金額を読み取り（手入力も可）。
- **支払方法**：現金（釣銭機自動払出）／キャッシュレス（UA-P10NA・**半連動/金額連動**の2モード）／QR（PayPay静的QR）。
- **レシートは原則このPOSから出さない**：医療の**領収書はレセコン**、クレジット**利用控えはUA-P10NA本体**が発行。POS印字は既定OFF（現金の預り/釣銭メモを紙で出したい院のみ任意ON）。
- **ハード無しで動く**：釣銭機/決済端末/プリンタは**シミュレータ同梱**。実機は設定＋ドライバ差し込みで切替。

## 使い方（デモ＝ハード不要）

```bash
npm install        # ws のみ（serialport は実機時のみ）
npm start
```

- 患者側：<http://localhost:8080/patient>
- スタッフ側：<http://localhost:8080/staff>

ブラウザを2つ開けば、片方の操作がもう片方に即ミラーされます（＝両面タッチの動作確認）。
現金投入は**デモ用ボタン**（シミュレータ時のみ表示）でエミュレートできます。

## 実機への切替

`config.json` を編集：
- `changeMachine.driver` を `"glory-rt"`、`serial.path` を接続ポートに。
- `printer.driver` を `"escpos-network"`（または `"escpos-serial"`）に。
- `npm install serialport @serialport/parser-inter-byte-timeout`

釣銭機の制御プロトコルは **`docs/釣銭機プロトコル.md`** の手順で「後差し込み」します
（上位アプリ・UIは無改修）。

## ディレクトリ

```
config.json                     運用設定（ここだけで実機/シミュレータ切替）
backend/src/
  server.js                     HTTP静的配信 + WebSocketハブ（ミラーの要）
  checkout/CheckoutSession.js   会計ステートマシン
  devices/changeMachine/        釣銭機：抽象I/F + Glory実機骨組み + シミュレータ
  devices/cashless/             決済端末：抽象I/F + 連動実機骨組み + シミュレータ（半連動/金額連動）
  devices/printer/              プリンタ：ESC/POS + シミュレータ + レシート整形（任意・既定OFF）
  receipt/billParser.js         レセコン領収書バーコード→金額パーサ
  util/                         金種計算・ログ
frontend/public/                患者/スタッフ両対応の1画面（role で切替）+ 多言語
```

## 設計上の注意（正直な論点）

- 会計の正確性は医療の信頼に直結。**導入初期は従来レジと二重運用で締め確認**を。
- **静的QRは自動照合ではなく目視確認運用**。取り違え防止のルールを明文化。
- 中古釣銭機は当たり外れあり。整備済み品＋**予備1台**の入替戦略を推奨。
- 釣銭機の**上位手順仕様書はNDA資料**。本ソフトは差し替え式で対応（詳細は該当doc）。
- キャッシュレスの規約・手数料・PCI等は各社契約に従う（本ソフトはカード情報を扱わない）。
