# キャッシュレス連携（UA-P10NA）

## 大前提（正直な結論）

UA-P10NA は **シャープ×NTTデータ**が共同開発し、NTTデータのクラウド決済基盤
**「CAFIS Arch」** 上で動く多決済端末です。したがって：

> **契約・登録・問い合わせなしに、こちら側だけで端末へ金額を「自動送信」することはできません。**
> 理由は仕様書が無いからではなく、**端末側で「CAFIS Arch POS連動」を有効化（契約）しないと、
> 外部からの金額入力を受け付けない**設計だからです（PCI準拠の決済端末として当然の作り）。

そこで本ソフトは、**契約ゼロ・こちら側だけで完結する現実解**を既定にしています。

---

## 契約なしで手打ちを減らす方法（実装済み・既定）

`cashless.mode = "semi"`（既定）。「キャッシュレス」を選ぶと、スタッフ画面が
**端末入力ガイド**になります。

1. **金額を大きく表示** … レセコンのバーコードから得た会計金額を大きく出すので、
   UA-P10NA に見ながら入力（打ち間違い防止）。
2. **金額バーコードを表示**（`cashless.showAmountBarcode = true`）…
   会計金額を **Code39 バーコード**で画面に表示します。
   **UA-P10NA がバーコード金額入力に対応していれば、これを端末で読み取らせるだけで手打ちゼロ**。
   （バーコードは外部ライブラリ無しの自前生成：`frontend/public/barcode.js`）
3. 決済が終わったらスタッフが「**端末承認を確認**」を押す → 完了。
   利用控え（承認番号入り）は **UA-P10NA 本体が発行**します（POSからは印字しない）。

> ①は必ず使えます。②は「端末がバーコードで金額入力できるか」に依存します。
> 対応していれば実質“連動”、非対応でも①で運用は成立します。**どちらも契約不要**。

### バーコード金額入力に対応しているか確認する方法

- UA-P10NA の売上（金額入力）画面で、**バーコード読取アイコン/操作があるか**、
  取扱説明書やメニューで確認する。
- 対応していれば、画面のバーコードを端末で読ませて金額が入るかテストする。
- 記号種別が合わない場合は `cashless.barcodeSymbology` の実装を差し替え可能（既定 Code39）。

## （将来）本当の金額自動連携をしたくなったら＝要契約

手打ちも読取も無くし、**選択→端末へ自動送金→承認で自動完了**にしたい場合は、
**CAFIS Arch の「POS連動」** を使います。これは契約・登録が前提です。

- 参考: NTTデータ「CAFIS Arch POS連動仕様について」/ 仕様書は登録制ダウンロード。
- クリニックなら **日本医師会 ORCA管理機構**経由の「キャッシュレス端末とPOSレジ連携」窓口が近道。
- **既製の OPOS/OCX ドライバ**（ソリマチ技研 等）を使えば、生電文を実装せず連携できる可能性。

本ソフトは将来の auto 連携も見据え、`cashless.mode = "auto"` と
差し替え式ドライバ（`backend/src/devices/cashless/LinkedCashlessTerminal.js`）を残しています。
`PROTOCOL` / `_buildRequest()` / `_onData()` を CAFIS Arch POS連動（または OPOS ブリッジ）向けに
実装すれば、上位（会計ロジック・UI）は無改修で auto 化できます。

### auto の動作（シミュレータで確認可能）

`config.json` を `mode:"auto"`, `link.driver:"simulator"` にすると、ハード無しで
「選択→処理中→自動承認→完了」を体験できます（`simulateApprovalMs` 後に自動承認、
スタッフ画面の［デモ］承認/否認ボタンで任意に発生）。フェーズ：

```
BILL_READY ─(選択)→ CASHLESS_PROCESSING ─(承認)→ COMPLETE
                          ├─(否認)→ CASHLESS_DECLINED ─(再試行)→ CASHLESS_PROCESSING
                          └─(取消)→ BILL_READY / IDLE
```

## モード早見表

| モード | config | 手打ち | 契約 | 動作 |
|---|---|---|---|---|
| **semi（既定）** | `mode:"semi"` | ①見て入力 / ②バーコード読取で不要 | **不要** | ガイド表示→決済→「端末承認を確認」 |
| **auto** | `mode:"auto"` | 不要 | **必要（CAFIS Arch POS連動）** | 選択→自動送金→承認で自動完了 |

## 運用上の注意

- クレジット利用控え・承認番号は **UA-P10NA 本体**が発行。POSでは印字しない（二重発行防止）。
- 通信断・取消時に端末の実売上と画面表示が食い違わないよう、**端末のジャーナルと締めで突合**する運用を。
- 本ソフトは**カード番号等の機微情報を保持しません**。
