# 運用マニュアル（スタッフ向け）

## 1会計の流れ

### ① 金額を確定する（スタッフ側）
- レセコンの**領収書バーコードをスキャン**、または画面下の入力欄に**金額を手入力**して「確定」。
- 患者側・スタッフ側の両画面に **お会計金額** が表示されます。

### ② 支払方法を選ぶ（患者 or スタッフ、どちらの画面からでも）
- **現金** / **クレジット・電子マネー** / **QRコード決済** から選択。
- 両面タッチなので、患者が迷ったら**スタッフ側からも同じ操作**ができます。

### ③ 支払い

**現金の場合**
1. 患者が釣銭機に現金を投入 → 画面の「お預り」が増えます。
2. 必要額に達したら「**支払う**」を押す → 釣銭機がお釣りを払い出します。
3. お釣りを受け取って完了。**領収書はレセコンが発行**します（このPOSからは出しません）。

**クレジット・電子マネー（UA-P10NA）の場合**

- **金額連動（auto）で運用しているとき**：
  1. 「キャッシュレス」を選ぶと、**金額が自動で UA-P10NA に送られ**、画面が「処理中」になります。
  2. 患者がカード/タッチで決済 → **承認されれば自動で完了**（スタッフの手打ち・確認ボタンは不要）。
     **クレジット利用控え（承認番号入り）は UA-P10NA 本体が発行**します。
  3. 否認されたら画面に理由が出るので「もう一度」で再試行、または「取消」。
- **半連動（semi）で運用しているとき**：
  1. スタッフが **UA-P10NA** で金額を打ち、患者がカード/タッチで決済。
  2. 端末が**承認**されたら、スタッフ画面の「**端末承認を確認**」を押す → 完了（利用控えはUA本体）。

> どちらのモードかは `config.json` の `cashless.mode`（`auto`/`semi`）で決まります。詳細は `docs/キャッシュレス連携.md`。

**QRコード決済（PayPay等）の場合**
1. 患者が札立ての**QRを読み取り**、アプリで金額を入力して支払い。
2. スタッフが**着金を目視確認**し、「**着金を確認**」を押す → 完了。

### ④ 完了
- 「ありがとうございました」表示後、一定時間で自動的に次の会計待機へ戻ります。
- すぐ次に進めたいときはスタッフ画面の「**次の会計へ**」。

## 取消・やり直し
- スタッフ画面の「**取消**」でいつでも中断。**現金は自動で返却**されます。

## 注意・チェック
- スタッフ画面右下に **釣銭機／プリンタの状態**と**在庫僅少の金種**が出ます。僅少金種は早めに補充。
- **静的QRは自動照合ではありません**。必ずアプリの支払完了画面（着金）を目視確認してから「着金を確認」を。
- 導入初期は**従来レジと二重で締め確認**し、金額差異が出ないことを確認してください。

## トラブル時
- 画面が「切断（再接続中）」→ ネットワーク/サーバを確認（自動で再接続します）。
- 釣銭機が「未接続/エラー」→ ケーブル・電源・詰まりを確認。回復しない場合は**予備機と入替**。
- 領収書は**レセコン**、クレジット利用控えは**UA-P10NA本体**から出ます。このPOSからのレシート印字は既定OFFです（`config.json` の `printer.enabled`）。
