# 運用マニュアル（スタッフ向け）

このPOSは **現金会計（自動釣銭機）専用**です。カード/電子マネーは **UA-P10NA 単体**、
PayPay等は **静的QR（札立て）** で、これまでどおり **POSとは別に** 対応します。

## 現金会計の流れ（このPOS）

### ① 金額を確定する
- レセコンの**領収書バーコードをスキャン**、または入力欄に**金額を手入力**して「確定」。
- 確定すると**支払方法の選択は省略**され、ただちに **「現金を投入してください」** になります。

### ② 現金の投入・釣銭
1. 患者が釣銭機に現金を投入 → 画面の「お預り」が増えます（釣銭機の客面表示にも出ます）。
2. 必要額に達したら「**支払う**」を押す → 釣銭機がお釣りを払い出します。
3. お釣りを受け取って完了。**領収書はレセコンが発行**します（このPOSからは出しません）。

### ③ 完了
- 「ありがとうございました」表示後、一定時間で自動的に次の会計待機へ戻ります。
- すぐ次に進めたいときはスタッフ画面の「**次の会計へ**」。

## 取消・やり直し
- スタッフ画面の「**取消**」でいつでも中断。**現金は自動で返却**されます。

## カード/QRで支払う患者への対応（POSの外）
- **カード・電子マネー**：**UA-P10NA** に金額を入力して決済（利用控えは端末が発行）。このPOSは使いません。
- **PayPay等**：**静的QR**を患者がスキャン→スタッフが**着金を目視確認**。このPOSは使いません。
- ※これらは現金を使わないので、このPOS（釣銭機）には通しません。

## 注意・チェック
- スタッフ画面右下に **釣銭機の状態**と**在庫僅少の金種**が出ます。僅少金種は早めに補充。
- 導入初期は**従来レジと二重で締め確認**し、金額差異が出ないことを確認してください。
- 現金／カード／QR を含む一日の合計は、**レセコンの会計記録や UA-P10NA のジャーナル**と突合してください
  （このPOSは現金分のみを扱います）。

## トラブル時
- 画面が「切断（再接続中）」→ ネットワーク/サーバを確認（自動で再接続します）。
- 釣銭機が「未接続/エラー」→ ケーブル・電源・詰まりを確認。回復しない場合は**予備機と入替**。
- 領収書は**レセコン**、クレジット利用控えは**UA-P10NA本体**から出ます。このPOSからのレシート印字は既定OFFです（`config.json` の `printer.enabled`）。
