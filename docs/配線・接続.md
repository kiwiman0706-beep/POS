# 配線・接続ガイド（1台PC + 2画面構成）

```
                         ┌─────────────────────────────┐
                         │        ミニPC (Win/Ubuntu)    │
                         │   Node.js バックエンド常駐     │
                         └───┬───────┬───────┬─────┬────┘
        HDMI/USB(タッチ) ┌───┘       │       │     │
   ┌──────────────┐      │           │       │     │ LAN or USB
   │ 患者側タッチ  │◀─────┘           │       │     ▼
   │  モニタ 15.6" │                  │       │  ┌──────────────┐
   └──────────────┘                  │       │  │ レシート     │
        HDMI/USB(タッチ) ┌───────────┘       │  │ プリンタ     │
   ┌──────────────┐      │                   │  │ EPSON TM系   │
   │ スタッフ側    │◀─────┘                   │  └──────────────┘
   │  タッチモニタ │                          │ USB(HID)
   └──────────────┘                          ▼
                                       ┌──────────────┐
                        USB-シリアル    │ バーコード    │
                     ┌────────────────  │ リーダー      │
                     ▼                  └──────────────┘
              ┌──────────────┐
              │ 自動釣銭機    │   ← RS-232C（USB-シリアル変換でPCへ）
              │ Glory RT-300 │
              └──────────────┘

   キャッシュレス：UA-P10NA（独立運用・PCと非接続でOK＝半連動）
   PayPay：静的QRの札立て（電源・配線不要）
```

## 接続一覧

| 機器 | PCとの接続 | 備考 |
|---|---|---|
| 患者側モニタ | HDMI（映像）＋ USB（タッチ） | 拡張ディスプレイ2枚目 |
| スタッフ側モニタ | HDMI（映像）＋ USB（タッチ） | 拡張ディスプレイ3枚目 or 内蔵含む |
| 自動釣銭機 | USB-シリアル変換 → RS-232C | `config.json` の `serial.path`（例 `/dev/ttyUSB0`, Windowsは `COM3`） |
| バーコードリーダー | USB（HIDキーボード） | ドライバ不要。末尾Enter設定に |
| レシートプリンタ（**任意**） | LAN(9100) または USB | 原則不要（領収書=レセコン／利用控え=UA本体）。使う場合のみ `printer.enabled:true` |
| UA-P10NA | PC非接続（半連動） | 端末単独で決済、承認後に画面で確定 |

## 画面の割り当て（キオスク表示）

- 患者側モニタ：ブラウザで `http://localhost:8080/patient` を全画面（キオスク）表示。
- スタッフ側モニタ：`http://localhost:8080/staff` を全画面表示。
- Chrome系なら `--kiosk --app=http://localhost:8080/patient` 等で起動。

## OS別のシリアルポート名

- Linux：`/dev/ttyUSB0`（変換チップにより `/dev/ttyACM0`）
- Windows：`COM3` など（デバイスマネージャで確認）
