# 配線・接続ガイド（現金＋自動釣銭機 / スタッフ画面1枚）

```
              ┌─────────────────────────────┐
              │        ミニPC (Win/Ubuntu)    │
              │   Node.js バックエンド常駐     │
              └──┬──────────┬──────────┬─────┘
   HDMI/USB(タッチ)│          │ USB(HID) │ USB-シリアル
   ┌──────────────┐│          ▼          ▼
   │ スタッフ側    ││   ┌──────────┐  ┌──────────────┐
   │ タッチモニタ  │◀┘   │バーコード │  │ 自動釣銭機    │
   │  ×1(必須)     │     │リーダー   │  │ Glory RT-300 │ ←RS-232C
   └──────────────┘     └──────────┘  └──────────────┘
   ┌──────────────┐
   │ 客側ディスプレイ│◀── HDMI（映像のみ・任意／非タッチでよい）
   │  (任意)        │
   └──────────────┘

   キャッシュレス：UA-P10NA（POSの外で単体運用・PCと非接続）
   PayPay：静的QRの札立て（電源・配線不要）
```

## 接続一覧

| 機器 | PCとの接続 | 備考 |
|---|---|---|
| スタッフ側モニタ（**必須**） | HDMI（映像）＋ USB（タッチ） | これ1枚で現金運用が回る |
| 客側ディスプレイ（**任意**） | HDMI（映像のみでよい） | 付ける場合。タッチ不要（表示だけ）。投入額/釣銭は釣銭機の客面表示でも足りる |
| 自動釣銭機 | USB-シリアル変換 → RS-232C | `config.json` の `changeMachine.serial.path`（例 `/dev/ttyUSB0`, Windowsは `COM3`） |
| バーコードリーダー | USB（HIDキーボード） | ドライバ不要。末尾Enter設定に |
| レシートプリンタ（**任意**） | LAN(9100) または USB | 原則不要（領収書=レセコン）。使う場合のみ `printer.enabled:true` |
| UA-P10NA | **PC非接続** | POSの外で端末単体で決済 |

## 画面の割り当て（キオスク表示）

- スタッフ側モニタ：ブラウザで `http://localhost:8080/staff` を全画面（キオスク）表示。
- 客側ディスプレイ（付ける場合）：`http://localhost:8080/patient` を全画面表示。
- Chrome系なら `--kiosk --app=http://localhost:8080/staff` 等で起動。

## OS別のシリアルポート名

- Linux：`/dev/ttyUSB0`（変換チップにより `/dev/ttyACM0`）
- Windows：`COM3` など（デバイスマネージャで確認）
